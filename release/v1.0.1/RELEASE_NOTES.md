The GitHub README now shows crisp, separate Light and Dark screenshots rendered at 1344×1216. We also rebuilt the WeChat, Xiaohongshu, LinkedIn, and X images from the sharper Chinese and English UI visuals. LiteFocus's one-activity, one-goal behavior is unchanged.

## Download / 下载

- macOS 14+ · Apple Silicon arm64
- Ad-hoc signed, not notarized / ad-hoc 签名，未经过 Apple 公证
- Download `LiteFocus-1.0.1-macOS-arm64.zip` and `SHA256SUMS`; run `shasum -a 256 -c SHA256SUMS` in the download folder.
- 首次打开可在 Finder 中右键点击 App，选择“打开”。

See [install and data](https://github.com/victor-zhang-2026/LiteFocus/blob/v1.0.1/docs/install-and-data.md) and [privacy](https://github.com/victor-zhang-2026/LiteFocus/blob/v1.0.1/docs/privacy.md).
