# LiteFocus 1.0.0 · First release

**One Focus. One Thing. One Goal.**

LiteFocus keeps one current activity and one goal visible on your Mac. Hover over the yellow sprout ball to view them, click either field to edit, Pin the panel when you want it to stay, or Clear both fields in one click. No lists, history, reminders, AI, or analytics.

LiteFocus 只保存一个当下事项和一个目标。鼠标悬停展开，点击字段编辑，Pin 固定面板，Clear 一键清零。没有多事项、历史、提醒、AI 或统计。

## Included / 包含

- Native macOS 14+ app for Apple Silicon (arm64)
- Chinese and English interfaces; Light and Dark modes
- Display-relative floating position and persistent Pin state
- Local, plaintext preference storage; no account or network service

## Download / 下载

Download `LiteFocus-1.0.0-macOS-arm64.zip` and `SHA256SUMS`, then run `shasum -a 256 -c SHA256SUMS` in the download folder. Unzip and open `LiteFocus.app`. The app is ad-hoc signed and not notarized; on first launch, right-click it in Finder and select Open.

下载 ZIP 与 `SHA256SUMS` 后，在同一目录运行 `shasum -a 256 -c SHA256SUMS`。解压打开应用。首次启动如受 macOS 提示，请在 Finder 中右键点击 App 并选择“打开”。

See [install and data](https://github.com/victor-zhang-2026/LiteFocus/blob/v1.0.0/docs/install-and-data.md) and [privacy](https://github.com/victor-zhang-2026/LiteFocus/blob/v1.0.0/docs/privacy.md).
