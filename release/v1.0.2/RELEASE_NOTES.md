# LiteFocus 1.0.2 · Cleaner editors

The two text fields no longer show scrollbar tracks when empty. Editing, scrolling, local persistence, and Clear remain available.

两个输入框在空白时不再显示右侧滚动条轨道。输入、滚动、本地保存和清零功能保持可用。

## Download / 下载

- macOS 14+ · Apple Silicon arm64
- Ad-hoc signed, not notarized / ad-hoc 签名，未经过 Apple 公证
- Download `LiteFocus-1.0.2-macOS-arm64.zip` and `SHA256SUMS`; run `shasum -a 256 -c SHA256SUMS` in the download folder.
- 首次打开可在 Finder 中右键点击 App，选择“打开”。

See [install and data](https://github.com/victor-zhang-2026/LiteFocus/blob/main/docs/install-and-data.md) and [privacy](https://github.com/victor-zhang-2026/LiteFocus/blob/main/docs/privacy.md).
