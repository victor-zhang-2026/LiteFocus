# 隐私 / Privacy

LiteFocus 没有账户、联网业务、服务器、遥测、广告或分析。仅在本机偏好中保存当前事项、目标和窗口设置；文本为未加密明文。同机用户或有文件访问权限的软件可能读取，用户应自行决定是否备份。应用不申请摄像头、麦克风、通讯录或通知权限。

LiteFocus has no account, network service, server, telemetry, advertising, or analytics. It saves the current activity, goal, and window settings only in local macOS preferences. Text is not encrypted; other local users or software with file access may read it. The app does not request camera, microphone, contacts, or notification access.
