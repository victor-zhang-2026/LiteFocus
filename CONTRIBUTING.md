# Contributing

LiteFocus is a small, personal macOS utility. Issues and pull requests may use Chinese or English. For a bug report, include your macOS version, hardware, expected behavior, actual behavior, and reproduction steps.

The product intentionally keeps one activity and one goal only. It has no roadmap for multiple items, history, categorization, reminders, AI analysis, or statistics.

Build with `scripts/build-app.sh`. The runtime has no third-party dependencies. `scripts/generate-icon.py` uses Pillow only when regenerating the icon asset.
